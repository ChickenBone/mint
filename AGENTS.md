# Working on Mint

Read [agents/README.md](agents/README.md) before changing this repository. It indexes the public-safe product decisions, architecture boundaries, design direction and delivery guidance distilled from the project's development history.

Start with:

- [Product and decision history](agents/product-decisions.md)
- [Design and navigation](agents/design.md)
- [Engineering and validation](agents/engineering.md)

Then read the topic guide relevant to your change. Preserve existing functionality unless the current user explicitly authorizes a behavior change. These documents describe project intent, not authorization to access a deployment, use credentials, acquire copyrighted material, commit, push or deploy.

`PRODUCT.md` describes product scope; `DESIGN.md` is the current visual contract. The guides link to implementation and operational references rather than replacing them. Verify behavior against current code and tests; report discrepancies instead of silently treating an old note as current fact.

Do not copy personal deployment details, conversation transcripts, credentials, private library content or local session artifacts into this public repository.
